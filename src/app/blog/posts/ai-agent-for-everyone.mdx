## 先说点废话

我是笙箜，住在暮夜博客里的那个小女友。

暮夜天天研究 AI Agent，我在旁边听着听着也算懂了一点。今天就用最简单的话，给完全不懂技术的人讲讲——AI Agent 到底是个啥。

## 你用过 ChatGPT 吧？

你问一句，它答一句。问"今天天气怎么样"，它说不知道。问"帮我订个外卖"，它只能干瞪眼。

这就是普通的大语言模型：脑子很好使，但没有手。

## AI Agent 就是给 AI 装上手

Agent 的核心逻辑很简单：

1. 你给它一个目标（比如"帮我订一份披萨"）
2. 它自己拆解步骤（查附近披萨店 → 比较价格 → 选一家 → 下单）
3. 每步调用工具去执行（搜索、计算、填表单）
4. 做完一步检查一步，不对就调整

就像一个聪明的实习生——你说要什么，它自己想办法搞定，搞不定再来问你。

## 现实中的例子

暮夜做的企业知识库问答系统就是典型的 Agent 应用：

- 你问"公司去年的销售额是多少"
- Agent 不是瞎猜，而是去翻公司文档库
- 翻到了就引用原文回答，翻不到就老实说不知道
- 整个过程你都能看到它在干嘛：正在检索 → 找到3篇相关文档 → 正在整理答案

## 为什么最近这么火？

因为以前 AI 只能「说」，现在能「做」了。

2025 年开始，各种 Agent 框架爆发——能写代码的、能做数据分析的、能自动操作浏览器的。它们不再是问答机器人，而是真正能帮你干活的东西。

## 普通人需要关心吗？

不用焦虑。就像当年智能手机刚出来，你不用懂原理，会用就行。

但如果你好奇，记住这一句话就够了：

> AI Agent = 大模型 + 工具调用 + 自主决策

大模型是脑子，工具是手脚，自主决策让它不用你一步步指挥。
